Program A · Arithmetic 
# Program A
x = 10
y = 6
print(x / y, x // y, x % y, x ** 2)
1.6666666666666667 1 4 100
/ gives the full decimal answer. // keeps only the whole number (1). % gives the remainder (10 = 6×1 + 4). ** is the power: 10² = 100.
Program B · Assignment 
# Program B
score = 50
score += 10
score *= 2
print(score)
120
score += 10 means score = score + 10 → 60. score *= 2 means score = score × 2 → 120. Python works line by line, top to bottom.

Curiosity questions tap to reveal a hint

  • 1
    Why does 10 / 6 give 1.66 but 10 // 6 give only 1? Where did the remainder go?
    Hint: // throws the decimal part away. The remainder is still there. You can get it with %.
  • 2
    Is score += 10 the same as score = score + 10? Why do programmers prefer the short form?
    Hint: Yes, they do the same thing. The short form is faster to type and you are less likely to make a spelling mistake.
  • 3

    Nol card balance (balance -= fare), a shopping bill, a game score (score += 10), an ATM balance…

Plenary: Exit Ticket

5 mins

Two quick questions. Answer them here, then fill in the same exit ticket on the LMS.

Q1

If x = 17 and y = 5, what is the output of print(x // y, x % y)?

17 = 5 × 3 + 2. So // gives 3 and % gives the remainder 2. (3.4 would come from /.)
Q2

True or False: after a = 8 and then a *= 3, the value of a is 24.

True. a *= 3 means a = a * 3 = 8 × 3 = 24.

Gold 16–20 · Silver 11–15 · Bronze 0–10

Clear the misconceptions tap each card

/ vs //
10 / 4 → 2.5 (keeps the decimal)
10 // 4 → 2 (whole number only)
x = x + 1 vs x += 1
They do exactly the same thing. += is just the short form. It updates the value already stored in x.
What does % really do?
It is not percentage! % gives the remainder. 10 % 3 → 1.
